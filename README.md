# TPY Hub — ระบบงานบุคคล วิจัยและนวัตกรรม โรงพยาบาลตาพระยา

เว็บ: https://tpy-hr.com

## ความสามารถ

- **การลา:** ยื่นลาได้ทั้งเต็มวันและครึ่งวัน หัวหน้างานอนุมัติ ดูวันลาคงเหลือตามปีงบประมาณ และพิมพ์แบบใบลาได้
- **บุคลากร:** ทะเบียนประวัติ ตำแหน่ง ใบประกอบวิชาชีพ และแจ้งเตือนเมื่อใกล้หมดอายุ (ภายใน 90 วัน)
- **วิจัยและนวัตกรรม:** ส่งผลงานพร้อมไฟล์ PDF ผู้ดูแลพิจารณา ผลงานที่อนุมัติแล้วเผยแพร่ในคลังผลงานให้ทุกคนค้นหาได้

สิทธิ์ผู้ใช้มี 3 แบบ: เจ้าหน้าที่, หัวหน้างาน (เห็นและอนุมัติได้เฉพาะหน่วยงานตัวเอง), ผู้ดูแลระบบ

## รันบนเครื่อง

ต้องใช้ Python 3.10 ขึ้นไป ไม่ต้องติดตั้งไลบรารีเพิ่ม

```
python server.py --open
```

หรือดับเบิลคลิก `run.bat` แล้วเปิด http://127.0.0.1:8100 ครั้งแรกระบบจะให้สร้างบัญชีผู้ดูแลระบบ

ข้อมูลจริงเก็บไว้ที่ `data/` (เปลี่ยนตำแหน่งได้ด้วย `HUB_DB` และ `HUB_FILES`) ห้าม commit โฟลเดอร์นี้

## ติดตั้งบนเซิร์ฟเวอร์ (Ubuntu)

```
curl -fsSL https://raw.githubusercontent.com/NOK125/tpy-hub/main/deploy/install.sh | sh
```

เซิร์ฟเวอร์จะรันที่ `127.0.0.1:8100` ผ่าน systemd (`tpy-hub.service`) และเก็บข้อมูลที่ `/var/lib/tpy-hub` จากนั้นชี้ Cloudflare Tunnel มาที่ `http://localhost:8100` ถ้าจะอัปเดตเวอร์ชัน ให้รันคำสั่งเดิมซ้ำ

## ข้อจำกัดตอนนี้

- นับวันลาเฉพาะวันจันทร์–ศุกร์ ยังไม่หักวันหยุดนักขัตฤกษ์
- ใช้โควตาวันลาตามระเบียบข้าราชการโดยประมาณ ส่วนวันลาพักผ่อน (รวมวันสะสม) กำหนดรายคนได้ในหน้าบุคลากร
