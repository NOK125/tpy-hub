# TPY HR — ระบบงานบุคคล โรงพยาบาลตาพระยา

เว็บ: https://tpy-hr.com

## การเข้าใช้งาน

- เข้าสู่ระบบด้วย**เลขบัตรประชาชน 13 หลัก**
- รหัสผ่านครั้งแรกคือ**เลขบัตร 5 ตัวท้าย** และระบบบังคับให้ตั้งรหัสใหม่ (อย่างน้อย 8 ตัวอักษร) ก่อนใช้งาน
- ใส่รหัสผิด 5 ครั้ง บัญชีจะถูกล็อก 15 นาที ผู้ดูแลระบบกด "รีเซ็ตรหัส" ให้ได้ รหัสจะกลับเป็นเลขบัตร 5 ตัวท้าย
- สิทธิ์มี 2 แบบ: **ผู้ดูแลระบบ** (HR) และ **ผู้ใช้งาน**

## เมนู

| เมนู | ผู้ใช้งาน | ผู้ดูแลระบบ |
|---|---|---|
| ภาพรวม | ดูภาพรวม ดาวน์โหลด Excel / PDF | เหมือนกัน |
| แผนพัฒนาบุคลากร | ดูงบ ยอดใช้ และ timeline | นำเข้า Excel, เพิ่ม/แก้แผน, ตัดงบ |
| คำสั่ง, ตรวจสุขภาพประจำปี, รายงานการประชุม, เอกสารอื่น ๆ | เปิดและดาวน์โหลด PDF | อัปโหลด แก้ไข ลบ |
| HR Clinic | ส่งคำถามถึง HR และดูคำตอบ (เห็นเฉพาะของตัวเอง) | ตอบทุกคำถาม |
| ผู้ใช้งาน | – | นำเข้า Excel, เพิ่ม/แก้ไข, รีเซ็ตรหัส |

"ดาวน์โหลด PDF" ในหน้าภาพรวมจะเปิดหน้าต่างพิมพ์ของเบราว์เซอร์ ให้เลือกเครื่องพิมพ์เป็น "บันทึกเป็น PDF" (Save as PDF)

## ไฟล์ Excel สำหรับนำเข้า (.xlsx)

ดาวน์โหลดแบบฟอร์มได้จากปุ่ม "นำเข้า Excel" ระบบหาหัวตารางเองได้ภายใน 15 แถวแรก และลำดับคอลัมน์สลับกันได้

- **ผู้ใช้งาน:** ลำดับ, คำนำหน้า, ชื่อ, นามสกุล, หมายเลขบัตร, ตำแหน่ง, ระดับ
  - ถ้าเลขบัตรมีในระบบแล้ว ระบบจะอัปเดตชื่อ ตำแหน่ง และระดับ โดยไม่เปลี่ยนรหัสผ่าน
  - ระบบเตือนเมื่อเลขบัตรมีหลักตรวจสอบไม่ถูกต้อง เพราะอาจพิมพ์ผิด
- **แผนพัฒนาบุคลากร:** ลำดับ, หน่วยงาน, งบประมาณ, งบประมาณที่ใช้ไป
  - เลือกปีงบประมาณตอนนำเข้า
  - "งบประมาณที่ใช้ไป" ในไฟล์คือยอดที่ใช้ก่อนเริ่มใช้ระบบ การตัดงบหลังจากนั้นให้บันทึกในระบบ
  - ถ้านำเข้าซ้ำโดยลำดับเดิม ระบบจะอัปเดตข้อมูลโดยไม่ลบประวัติการตัดงบ

## รันบนเครื่อง

ต้องใช้ Python 3.10 ขึ้นไป ไม่ต้องติดตั้งไลบรารีเพิ่ม

```
python server.py --open
```

หรือดับเบิลคลิก `run.bat` แล้วเปิด http://127.0.0.1:8100 ครั้งแรกระบบจะให้สร้างบัญชีผู้ดูแลระบบ

ข้อมูลจริงเก็บไว้ที่ `data/` (เปลี่ยนตำแหน่งได้ด้วย `HUB_DB` และ `HUB_FILES`) ห้าม commit โฟลเดอร์นี้

## ติดตั้งหรืออัปเดตบนเซิร์ฟเวอร์ (Ubuntu)

```
curl -fsSL https://raw.githubusercontent.com/NOK125/tpy-hub/main/deploy/install.sh | sudo sh
```

ระบบรันที่ `127.0.0.1:8100` ผ่าน systemd (`tpy-hub.service`) และเก็บข้อมูลไว้ที่ `/var/lib/tpy-hub` Cloudflare Tunnel ชี้ `tpy-hr.com` มาที่ `http://localhost:8100` ถ้าจะอัปเดตเวอร์ชันให้รันคำสั่งเดิมซ้ำ ข้อมูลเดิมจะไม่หาย
